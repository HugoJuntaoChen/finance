# finance

个人股票投资 / 交易工作区。用于汇总分析思路、策略脚本，以及配套的 Claude Code skills。

## 目录结构

```
finance/
├── .claude/
│   └── skills/      # Claude Code skills（炒股相关工具，后续添加）
├── data/            # 行情 / 基本面等数据（不纳入版本管理）
├── notebooks/       # 研究与回测 notebook
├── scripts/         # 分析、抓取、回测脚本
└── README.md
```

## 用途

- 股票 / 半导体供应链等标的的研究与思路记录
- 策略脚本与回测
- 通过 Claude Code skills 复用常用分析流程

## 说明

仅供个人研究使用，不构成投资建议。
